# Windows 桌宠

v0.10.0 为现有 Little Pet 增加透明桌面窗口。默认使用高清桃铃狐，也可以在小窝设置中切回原版逐帧动画或蓝猫。

v0.10.1 修复初次打开小窝时的 `reading 'config'` 页面加载顺序问题，以及退出时连接清理超时。更新前从托盘退出桌宠；如果原网页服务也在运行，停止并重新启动该服务后再打开桌宠，确保正在运行的是新代码。

## 在已有项目里启动

先更新本分支源码，保留原目录的 `pet.config.json` 和整个 `data/`。双击 **start-desktop.cmd**；首次会安装运行依赖并下载 Electron。推荐 Node.js 24。

也可以在项目目录运行：

```powershell
npm ci --include=dev --ignore-scripts --no-audit --no-fund
npm run desktop
```

`npm run desktop` 会在首次使用时下载桌面运行环境。默认仍可用 `npm start` 打开网页版。

### 下载失败或出现 fetch failed

v0.10.1 起可以直接指定镜像，无需区分 CMD、PowerShell 或 Git Bash 的环境变量语法：

```text
npm run desktop:setup -- --mirror=cn
npm run desktop
```

`cn` 使用 Electron 文档列出的 `https://npmmirror.com/mirrors/electron/`；`official` 使用 GitHub 官方下载地址。也支持 `--mirror=https://你的镜像/`。参数只对当前下载生效，不修改系统设置。下载仍使用 Electron 包自带的校验值。

如果代理软件已启动，且 HTTP 或混合代理端口确实为 7890，可以执行（实际端口不同时替换）：

```text
npm run desktop:setup -- --mirror=official --proxy=http://127.0.0.1:7890
```

只接受 HTTP(S) 代理地址；浏览器能联网不代表 Node 下载自动使用了系统代理。已配置的 `HTTP_PROXY` / `HTTPS_PROXY` 也会启用下载代理。代理选项只传给安装子进程，不更改宠物模型或其他通道的网络配置。

安装器会显示当前下载源、代理主机和底层错误码。`ENOTFOUND` 表示 DNS 解析失败，`ECONNREFUSED` 表示连接被拒绝，超时错误表示连接未及时完成。下载失败只尝试一次，不会因检查安装状态而重复下载。下载完成后，后续启动直接使用本机运行环境。

手动设置环境变量时，CMD 使用 `set "ELECTRON_MIRROR=..."`，PowerShell 使用 `$env:ELECTRON_MIRROR = '...'`，Git Bash 使用 `export ELECTRON_MIRROR='...'`；这些写法不能混用。优先使用上面的命令参数。

源码模式直接使用项目原有数据。如果这个目录的网页服务已经启动，桌宠会连接它；此时退出桌宠不会停止你原来启动的服务。由桌宠启动的服务则会随桌宠正常退出。

## Windows 可运行包

GitHub Actions 的 **Windows desktop build** 工作流成功后，下载 `LittlePet-Windows-x64` 构建产物，解压**整个目录**，双击 **LittlePet.exe**。不需要另装 Node.js。不要单独复制 exe，旁边的运行库和 resources 也必须保留。

第一次运行可选择原来包含 `pet.config.json` 和 `data/pet.sqlite` 的宠物目录，继续使用已有模型配置、记忆与登录状态。这里直接使用原目录，不复制或删除原数据。稍后也可从托盘选择「使用已有宠物数据」。

新建小窝时，数据保存在 Windows 用户应用数据目录下的 `Little Pet` 文件夹；右键菜单「打开数据文件夹」可以找到。升级时只替换程序目录，保留数据目录。开发/自动化环境可用 `PET_DATA_ROOT` 指定数据根目录。

本版构建未配置代码签名。自行打包需要 Git 检出目录，只复制 Git 跟踪的程序文件：

```powershell
npm ci --include=dev --ignore-scripts --no-audit --no-fund
npm run desktop:build -- win32 x64
```

输出 `dist/LittlePet-win32-x64/`。打包通过源文件白名单和全新依赖安装完成，不包含本机配置、数据库、浏览器登录目录或日志。Windows 构建在 Windows 上执行；跨平台打包还可能要求额外的工具链。

## 怎么玩

| 操作 | 行为 |
| --- | --- |
| 点击宠物 / 键盘 Enter 或空格 | 摸头，显示互动气泡 |
| 按住拖动 | 移动桌宠；松开后记住位置，重新接屏时限制在可见工作区 |
| 双击 / 下方「聊聊」 / 气泡「回复」 | 在宠物上方展开桌面聊天面板，直接输入和发送 |
| 下方「语音」 | 展开面板并开始连续语音对话；再次点击结束 |
| 气泡或聊天记录上滚动 | 完整阅读长回复；可以选中文字并按 Ctrl+C 复制 |
| 面板「×」 / Escape | 收起聊天面板，停止录音、朗读和正在等待的回复；保留未发送草稿 |
| 面板「↗」 / 「语音设置」 | 需要更多功能时打开完整小窝或语音设置 |
| 右键 / 下方「•••」 | 投喂、抱抱、逗玩、跳舞、睡觉、叫醒、切换大小和置顶 |
| 托盘「显示 / 找回桌宠」 | 恢复隐藏或鼠标穿透的桌宠 |
| 免打扰 | 关闭主动分享与跨窗口互动气泡；你主动聊天的回复仍可以显示 |
| 关闭小窝窗口 | 隐藏小窝，桌宠继续运行 |
| 托盘「退出桌宠」 | 保存位置，停止本桌宠启动的后台服务 |

桌宠和网页小窝共用 `web:owner` 的聊天与养成状态；QQ / 微信各自的会话保持独立。桌宠气泡只显示主人小窝的新回复，不把其他人的消息展示到桌面。长消息不截断，也不会定时消失；短互动气泡在鼠标悬停或键盘聚焦时暂停收起。文字输入支持 Enter 发送、Shift+Enter 换行，输入法确认候选词时不会误发。

桌面语音复用小窝的语音输入、输出和音色设置，提供「说完了」「打断」「结束」及口述到输入框。仅在主动点击后收音，收起聊天、隐藏桌宠或退出时停止；再次显示不会自动恢复录音。配置语音识别后，可直接在桌宠上连续交谈。Electron 不保证提供 Chrome / Edge 的联网识别服务，无法使用浏览器识别时，请通过「语音设置」配置独立 STT；朗读可用系统声音或已配置的 TTS。桌面只允许本机页面的音频权限，摄像头与屏幕采集保持禁用。

桌面面板用于文字与语音，图片上传、账号管理和完整设置仍在小窝。展开和收起以窗口右下角为锚点，并限制在当前显示器工作区内；保存的位置按收起后的尺寸恢复。

Windows 上宠物外围透明像素自动允许鼠标穿透；「鼠标穿透」菜单可让整个宠物暂时不接收鼠标，此时从系统托盘恢复。开机启动仅在打包后的 Windows 应用中可选，默认关闭。

## 高清形象的范围

- 新图集 1254×1254，每帧 **627×627**，RGBA 真透明。原图每帧只有 192×208。
- 高清版有待机睁眼、眨眼、挥手、蜷睡四种姿态，配合轻微呼吸、思考与互动动效。没有把原来的全部动作逐帧高清化，也没有新增走路、洗澡或打工动画。
- 设置中的「桃铃狐 · 原版逐帧动画」保留原素材和原动画。已有 `appearance: taolinghu` 会显示高清版，名字、人设和养成数据不变。
- 默认中号适合一般桌面；高 DPI 屏幕可选小号或中号。没有通过关闭系统 DPI 适配来扩大低清素材。
- 尊重系统减少动态效果设置，隐藏窗口时暂停动画并降低状态查询频率。

## 验证范围

普通 `npm test` 覆盖后台服务启动/复用/退出、共享养成状态、主人的消息隔离、鉴权与来源保护、透明图集、位置恢复及网页兼容性。

`PET_DESKTOP_TEST=1` 的原生验收使用 Playwright 启动真实 Electron。Windows 工作流会对打包 exe 检查窗口、预加载隔离、互动、长气泡的滚轮滚动、直接文字聊天、音频权限与录音/播放、收起后释放麦克风、形象切换、小窝窄屏和服务退出，并保存截图；是否通过以该次工作流结果为准。音频验收使用 Chromium 虚拟麦克风、本机模拟模型/STT/TTS 和测试音频，不代表实际设备或服务商已经联调成功。

多显示器不同缩放比例下的真实拖动、系统托盘、开机启动及 Windows 麦克风仍应在用户实际桌面确认。语音沿用原来的 STT/TTS 配置；Electron 不保证提供浏览器厂商的联网语音识别，可选择已配置的独立 STT。

微信扫码的数字验证码步骤目前仍使用原有终端输入。若遇到这个步骤，可先在原项目用 `npm start` 完成绑定，再让桌宠连接该服务；桌宠没有新增验证码输入弹窗。
