# 搜索、记忆与宠物日记

v0.12.0 增加通用联网搜索、记忆上下文检查和每日手帐。升级后重启桌宠及其复用的旧网页服务。搜索和自动日记默认关闭，在相应页面开启；已有配置、记忆和聊天不会被替换。

## 联网搜索

到「设置 → 联网搜索」，选择服务并保存，然后点「测试一次搜索」。

| 服务 | 怎么配置 |
| --- | --- |
| Tavily | 在 [Tavily](https://www.tavily.com/) 获取独立搜索密钥；服务地址默认 `https://api.tavily.com`。聊天模型的密钥不能代替搜索密钥。 |
| SearXNG | 填写自己信任的实例根地址，实例须在 `search.formats` 中启用 `json`。本机可用 `http://127.0.0.1:端口`，远端须 HTTPS。程序不向 SearXNG 发送 Tavily 密钥。 |

开启后在小窝、桌宠或语音里说「搜索最近的 AI 新闻」「帮我找点有趣的」，或者输入 `/搜索 关键词`、`/search keywords`。普通聊天不调用搜索；只处理本轮明确的查找请求，暂不让模型自行连续搜索或打开任意网页。QQ / 微信需要额外勾选允许通道搜索。

v0.13.1 修复「再帮我看下网上有什么趣事」「帮我看看网上有什么新鲜事」没有触发搜索的问题。新回复下方会显示后台记录的「已联网搜索」「复用搜索结果」或「本条未联网搜索」，并显示服务和摘要数量；悬停可看关键词和取得时间。旧版消息没有保存这项状态，不追补推测。零结果由程序直接说明，不让模型编造搜索过程，空结果不缓存。

### 已填密钥但搜索失败

先保存，再点「测试一次搜索」。v0.12.0 的通用错误无法区分原因；v0.13.1 会保留 HTTP 状态码和安全的网络错误码，不显示密钥或原始服务响应。

| 提示 | 含义与处理 |
| --- | --- |
| HTTP 401 / 403 | 密钥或访问权限问题；SearXNG 还要检查 JSON 格式是否开启。 |
| HTTP 432 / 433 | Tavily 账户或套餐用量达到上限，查看 Tavily 控制台。 |
| HTTP 429 / 5xx | 服务限流或暂时不可用，稍后重试。 |
| ENOTFOUND / EAI_AGAIN | 域名解析失败，检查网络与 DNS。 |
| UND_ERR_CONNECT_TIMEOUT / SEARCH_TIMEOUT | 无法及时连接服务，检查网络及搜索代理。 |
| ECONNREFUSED | 连接被拒绝，核对代理是否启动和端口。 |
| 证书错误 | 检查系统时间、可信证书及代理，不关闭证书校验。 |
| SEARCH_INVALID_JSON / SEARCH_FORMAT | 收到的内容不是搜索 API 结果，核对服务地址，检查是否被网络中间页替换。 |

如果电脑访问 Tavily 需要本机代理，在「搜索代理（可选）」填 HTTP / Mixed 监听地址，例如 `http://127.0.0.1:7890`，端口以你的代理软件为准。此项仅用于搜索，不改变聊天模型连接；留空使用后台默认网络。支持本机 HTTP(S) 代理，不支持 SOCKS 地址、带账户密码的地址或远程代理。浏览器的连接方式不一定与 Node.js 后台一致。旧的 `desktop:setup --proxy` 只配置 Electron 下载，并不配置 Tavily 搜索代理。

代理更改会使原缓存失效；请求完成或取消后销毁代理连接。搜索结果的链接仍由用户点击在系统浏览器打开。

每轮最多获取五条摘要。答案带来源编号，小窝和桌宠显示可点击的真实来源；QQ / 微信在文字后附上来源地址。桌面来源链接由系统浏览器打开。结果是搜索摘要，不代表读过完整网页、看过图片或视频。后续聊天可参考本会话此前取得的摘要与取得时间。

只把当前搜索关键词发给搜索服务，不发整段历史、记忆或聊天模型密钥。模糊请求「找点有趣的」可附上探索页配置的兴趣关键词。搜索密钥保存在本机，也支持环境变量 `PET_SEARCH_API_KEY`；环境变量优先，修改或清除它需要在运行环境操作。切换服务或服务地址来源且未填写新密钥时，不沿用旧的文件密钥。

默认每天最多请求 30 次，按 UTC 日期重置，QQ / 微信与小窝共用上限。网络请求前计数，失败也占一次；同一会话、关键词和配置下五分钟内复用结果，缓存最多 50 项。搜索失败会给出错误，不拿模型旧知识冒充搜到的资料。服务商可能另有额度或计费，以其控制台为准。

协议参考：[Tavily Search API](https://docs.tavily.com/documentation/api-reference/endpoint/search)、[SearXNG Search API](https://docs.searxng.org/dev/search_api.html)。Tavily 使用 basic、关闭生成答案和全文获取；SearXNG 使用 POST 表单和 JSON 结果。没有自动访问结果 URL。

## 知道它记住了什么

在小窝「记忆」选择会话；桌宠聊天面板上方的 **▤** 也可直接打开。

- **长期记忆**：实际保存的条目和日期，可添加、编辑或删除。用 `/remember 内容` 也能保存；当前不会悄悄从所有对话自动提取记忆。
- **最近聊天上下文**：本会话模型会参考的最近 24 条消息，可展开查看，与长期记忆分开。
- **已分享的探索资料**：当前会话确实分享过的小红书笔记摘录。其他用户会话不会显示主人资料。
- **搜索资料**：随相应聊天消息保存，来源链接和摘要属于那次搜索；不会自动变成长期记忆。

直接问「你记得我什么？」或发 `/记忆`、`/memories`，会从数据库返回本会话的真实长期记忆，不由模型猜测。聊天中最多列出前 20 条的简要内容，完整内容在记忆页。

删除长期记忆不删除已有聊天或日记，因此它仍可能从最近聊天中看到同样的事实。希望不再参考时，可另外清空对应聊天；日记可独立删除。编辑后的记忆会在下一次聊天使用。

## 每天写日记

打开「日记」，开启 **每天自动写一篇日记**，保存时间和时区，默认时间为上海时区 **21:30**。桌宠聊天面板上方的 **✎** 可打开日记。

程序运行时每分钟检查一次，到点后用当前聊天模型写一篇第一人称手帐。资料只来自主人小窝/桌宠当天的聊天、虚拟互动和真正读取的探索内容，不混入 QQ / 微信，也不把日记自动回灌成长期记忆。表达可以带角色心情，提示要求不编造当天没有发生的用户活动；生成文字仍可能有模型误差。

每天只保存一篇，重启或重复点击不会重复调用。手动选择日期点「写下这一天」可补写；已写过的不会覆盖。没有可用记录的日子使用明确说明无记录的简短本地文字，不调用模型。

电脑关机或程序退出时不会写。下次启动若昨天有保留的聊天且还没写过，会补写昨天；不会无限补旧历史。自动生成失败一小时后再尝试，手动仍可重试。普通聊天保留最多 500 条，日记输入取该日仍保留的最近 100 条、每条最多 1200 字，互动和探索也有既有保留上限，因此日记不是所有活动的完整备份。

日记保存在 `data/pet.sqlite` 的独立表中，列表显示最近 366 篇。删除时清除正文并保留日期标记，避免定时器重新生成已删内容。清空聊天、取消写作或修改模型/日记设置后，相关迟到结果不会保存。

## 验证范围

自动测试使用本机模拟搜索、模型和虚拟麦克风，覆盖协议、密钥隔离、查询与会话隔离、额度/缓存、取消与设置变更、持久化来源、记忆读取和编辑、日记去重与删除、时区边界和隔日补写。Windows 验收检查打包程序的搜索来源、记忆编辑、日记生成/删除和窄屏页面。真实搜索服务的可达性、额度和实际日记文风需要在用户配置的服务上确认。
