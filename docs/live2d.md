# Live2D 形象

## 启用

1. 更新到 v0.14.0，退出桌宠并重启正在复用的网页服务。
2. 在「设置 → 形象与人设 → 宠物形象」选择 **Haru · Live2D 官方示例**，保存。
3. 回到小窝，或直接看桌面宠物。名字、人设和养成记录沿用现有设置；想切回桃铃狐，在同一个下拉框选择即可。

运行库、模型、贴图和动作全部随程序提供，显示动画无需 CDN、代理、额外 API Key 或摄像头。第一次加载时保留原形象，模型准备好后切换。已有聊天/语音仍使用你配置的服务。

## 这一版的表现

| 场景 | 实际行为 |
| --- | --- |
| 待机 | Cubism 网格连续变形，播放模型待机动作，配合呼吸、眨眼和头发物理 |
| 鼠标移动 | 视线和头部平滑跟随；桌面窗口外的鼠标也可跟随 |
| 摸头、投喂、拥抱、玩耍、跳舞、叫醒 | 映射到 Haru 自带的互动动作，并叠加短暂笑脸；不是为这些活动新制作的全身动作 |
| 睡眠与思考 | 渐进闭眼、低头休息，或轻微歪头；仍沿用原有养成规则 |
| 独立 TTS 音频 | 仅在音频实际播放时，根据音量驱动张嘴；缓冲、暂停、取消和播放结束停止 |
| 系统朗读 | 系统不暴露音频波形，在实际开始朗读后用近似口型；并非音素级对口型 |
| 隐藏窗口、离开小窝、系统减少动态效果 | 停止动画循环；换形象时释放模型、贴图和事件监听 |
| 绘图环境不可用或资源缺失 | 显示具体提示并暂时恢复桃铃狐；修复后先切到其他形象，再选 Haru 或刷新重试 |

使用 `requestAnimationFrame` 和真实时间推进，渲染上限 60 Hz；实际帧率取决于设备、显卡驱动与系统负载，不保证所有电脑恒定 60 FPS。像素密度最高按 2 倍处理。模型透明区域可鼠标穿透，工具栏与聊天面板仍可操作。

## 桃铃狐专属模型

当前集成的是 **Live2D 官方原创示例 Haru**，没有把现有桃铃狐 PNG 假装成 Live2D。桃铃狐目前仍只有逐帧素材；专属模型需要可拆分的高分辨率分层立绘、补齐被遮挡部位，在 Cubism 中制作网格、参数、变形器和物理，再导出 `.moc3`、`.model3.json`、贴图与动作。单张图的放大或 CSS 摇晃不能替代这项制作。

本版只提供固定内置模型，不开放任意目录或远程模型导入。以后完成专属模型后，可复用当前渲染、互动与语音连接；模型参数和动作名称需要重新映射。骨骼动画尚未加入。

## 来源、维护与许可

完整归属、来源和授权链接在 [NOTICE.txt](../web/vendor/live2d/NOTICE.txt)。Haru 的样例素材、Cubism Core 和 Cubism Framework 分别按各自条款使用，不因加入本仓库而变成同一种开源许可；发布者、用途及是否允许用户扩展模型都可能影响授权要求。

- **Core 5.1.0**：官方公开运行库原文件，SHA-256 `25ae938cb4fe282ce189b357bcc97e603d1e1f7ec78bf04150d401c23cdc792f`，未修改。
- **Framework 5-r.4**：固定提交 `8df84780f2aa1298f3b30965cdae143e049f3c8e`，由 esbuild 打成一个本地 ESM 文件；保留官方源文件的许可依据。无需运行构建脚本即可启动项目。
- **Haru**：官方 Samples 提交 `b1de66b0b1f1cb881d95fb6158622aeb6a2827bd`。仅移除了清单里的未使用声音、显示信息和用户数据引用；未修改模型几何或原画，没有打包或播放示例语音。

维护者重建 Framework：将官方仓库检出到上述固定提交，安装本项目开发依赖，再执行：

```text
node scripts/build-cubism.mjs /path/to/CubismWebFramework
```

升级运行库或模型时同时检查版本兼容、来源校验、许可及 `pet/live2d-assets.mjs` 的精确资源白名单；不要改为开放任意静态路径。页面 CSP 只增加 WebAssembly 运行所需的 `wasm-unsafe-eval`，未开放 JavaScript 字符串执行。

自动验收包含真实 `.moc3` 顶点变形、资源路由与配置兼容，Chromium 的绘制/跟随/音频口型/换装/暂停/错误回退，以及 Windows 打包 exe 的透明绘制与窗口隐藏恢复。截图保存在工作流的 `live2d-qa` 和 `desktop-qa` 构建产物中。真实麦克风、声卡及用户服务商效果仍需要在自己的电脑上体验。
