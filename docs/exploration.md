# 小红书探索与主动聊天

v0.8.0 在独立宠物中新增「探索」。宠物按你填写的兴趣轮换浏览小红书图文，读到有话题的内容后在「小窝」发起聊天，并附原文链接。支持正文，以及可选的配图、视频抽帧与短音频转写；不执行点赞、评论、发帖或私信。

## 更新和启动

1. 关闭原来的宠物程序。建议先复制备份 `data/` 与 `pet.config.json`。
2. 将 v0.8.0 源码包中的文件复制到原项目目录，覆盖同名源码。源码包不含真实配置、账号或数据，不要删除你原来的 `data/` 与 `pet.config.json`。
3. Windows 双击 `start.cmd`。启动脚本会检查新增运行依赖，缺少时自动安装。也可在目录运行：

```powershell
npm ci --omit=dev --ignore-scripts --no-audit --no-fund
npm start
```

4. 浏览器打开 `http://127.0.0.1:3210`，按 Ctrl+F5 刷新旧页面。原来修改过端口时，以终端显示的地址为准。
5. 确保「设置」里的聊天模型已能正常回复。每次探索最多调用一次聊天模型来决定是否分享。启用媒体分析后，每篇最多增加一次视觉模型调用（每轮最多 3 次），视频最多增加一次 STT 调用，产生对应服务用量。

Windows 默认优先使用已安装的 Edge，再尝试 Chrome/Chromium；可以在探索页选择。若提示找不到浏览器，双击 `install-browser.cmd`，或运行：

```powershell
npm run browser:install
```

Linux 扫码登录需要图形桌面；没有图形桌面的服务器不能直接完成这个本机扫码流程。

## 第一次连接

1. 打开「探索」，点击「打开小红书登录」。
2. 程序在运行宠物的同一台电脑上打开独立浏览器；用小红书 App 扫码登录。不会读取你平时使用的 Chrome/Edge 配置。
3. 若出现验证码或安全验证，在浏览器中自行完成。
4. 登录完成后，程序每 30 秒在已有窗口中检查登录标识；不必先点「检查登录」，可以直接点「现在去逛逛」。手动检查也会保留窗口，不会重新打开后台浏览器。
5. 填写 1–10 个感兴趣的话题，设置频率和免打扰，再勾选「允许自动探索，并在小窝主动找我聊天」，点击保存。新安装与升级都不会静默开启这个开关。
6. 可以先点「现在去逛逛」，在动态中观察结果。手动探索也会遵守免打扰、聊天冷却和每日限额。

浏览期间如果登录失效或需要验证码，会暂停后续自动浏览。已经打开的可见窗口会保留在当前页面，重复点击「打开小红书登录」只会唤起它。请在该窗口手动完成验证；程序识别到登录后解除暂停，也可点「检查登录」或「现在去逛逛」主动检查。后台浏览遇到验证时，再打开登录窗口会返回出错的站内页面。无需粘贴 Cookie。

保存兴趣、模型等设置不会关闭空闲的登录窗口。窗口打开时，探索复用同一窗口和登录状态，即使勾选了隐藏窗口；手动关闭后，后续探索按该设置启动。点击「停止并关闭自动探索」、关闭自动探索开关或退出程序会关闭受控浏览器。登录成功不代表绕过聊天冷却、免打扰和每日限额。

## 默认节奏

| 设置 | 默认行为 |
| --- | --- |
| 自动探索 | 关闭，需自行开启 |
| 兴趣 | 数码科技、生活趣事；按顺序轮换，可修改 |
| 每轮阅读 | 最多 3 篇未读笔记；媒体分析需单独开启 |
| 探索间隔 | 60 分钟，可设为 30–1440 分钟 |
| 主动分享 | 每天最多 3 次，可改为 1–10 次 |
| 免打扰 | 23:00–09:00，Asia/Shanghai 时区 |
| 刚刚聊天 | 等待至少 10 分钟 |
| 两次分享未获回复 | 等待至少 12 小时 |
| 每日浏览预算 | 最多 24 轮，重启不重置 |

开始和结束时间相同表示关闭免打扰。免打扰期间不浏览、不调用模型。没有读到正文、内容重复或模型认为没必要聊时，可以整轮都不发消息；「去逛了」不等于必定发消息。

自动探索需要宠物后台、电脑和网络保持运行；关闭网页后后台仍会继续，之后打开小窝可看到消息。关机、睡眠或退出程序期间不会浏览；恢复后按保存的时间检查，不补刷一长串漏掉的任务。

## 消息、来源和手记

- 主动消息以宠物身份进入「小窝」，有「主动分享」标记、原文链接和未读数量。点击小窝后显示实际消息并清除已显示消息的未读。
- 可以问「刚才那篇说了什么」，模型会得到本会话近期已分享的笔记摘录。它会依据正文和已保存的观察摘要回答；不会在追问时自行重看原始媒体，也不会把抽帧描述成完整观看视频。
- 「探索手记」可查看真实读取到的文字；「清除手记」删除摘录、动态和主动消息，保留普通聊天、长期记忆、账号登录和每日预算。自动探索开关保持原设置。
- 「停止并关闭自动探索」会取消当前任务并保存关闭状态。重新启动程序也不会自行打开这个开关。

笔记摘录、媒体观察摘要、网页会话近期聊天和该会话长期记忆会发送给你在设置中指定的聊天模型，以决定是否分享。配图和视频帧只发送给设置中的视觉模型（优先独立图片模型）；短音频只发送给已配置的 STT。原始媒体仅在本轮内存中使用，不写入笔记数据库或长期保存。浏览器登录信息留在独立本机配置目录，源码包不含这些内容。微信会话不会自动参与网页探索。

## 常见情况

| 页面提示 | 处理 |
| --- | --- |
| 需要登录 / 安全验证 | 在登录窗口手动处理，再直接探索或检查登录 |
| 找不到浏览器 | 安装 Chrome/Edge，或运行 `npm run browser:install` |
| 暂无搜索结果 / 未启用视频分析 | 换一个兴趣话题，或开启视频分析；本轮不生成虚构分享 |
| 页面需要检查 / 没有正文 | 登录后检查是否能正常阅读；无结果可换兴趣；页面改版可能需更新选择器，程序不会用标题假装读过正文 |
| 免打扰中 | 等待设定时段结束，或调整自己的免打扰时间 |
| 刚刚聊过 | 主动聊天会等待至少 10 分钟 |
| 两次分享还没有收到回复 | 先回小窝和它聊一句，或等待安静间隔结束 |
| 模型决定无效 / 模型调用失败 | 检查聊天模型配置；待下一轮或稍后手动重试 |
| 关闭网页后没看到桌面通知 | 本版没有系统通知或悬浮窗，消息在小窝保存，重新打开可见 |

## 图片和视频分析

1. 在「设置」中选择实际支持图片的聊天模型并启用图片输入，或配置「独立图片模型」。原有文字聊天配置可保留。
2. 在「探索」勾选「分析笔记配图」和/或「分析视频画面」，保存。新增开关默认关闭，开启后只影响后续探索的笔记。
3. 如需理解视频讲话内容，在「设置」配置 STT，再勾选「同时转写视频前 20 秒音频」。未配置时仍可分析画面，但不会声称听过音频。
4. 在手记展开「阅读与观察记录」，查看正文、画面摘要、帧时间和音频区间；分享来源也会显示实际使用的证据范围。

每篇最多读取 3 张已加载的笔记配图；每轮最多处理 1 个视频，从其前 60 秒抽取最多 3 帧，音频最多 20 秒。浏览器只捕获该视频播放器的音频，不使用麦克风或系统录音，不安装 FFmpeg。受跨域、编码、加载、站点验证等限制的媒体会明确记录失败，保留可用正文继续处理；没有实际正文/观察时不生成分享，也不标为已读。视觉服务失败时不把画面标为已理解。抽帧无法用于判断整段视频的流畅度、全部动作或全部剧情。

媒体只从公开渲染的笔记详情元素读取。图片下载只允许 HTTPS 小红书及其 CDN，拒绝自动重定向和超量内容，不携带浏览器 Cookie。视频在浏览器中正常解码，不绕过验证码、访问限制或内容保护。观察摘要和转写属于模型生成/识别结果，可能有误；原始图片/音频不长期保存。

## 退出和切换小红书账号

- 点击「退出登录」会停止本轮任务、关闭自动探索并清除 `data/xiaohongshu-profile` 中这个独立浏览器的登录信息。它不会注销小红书账号，也不会影响你平时浏览器/手机里的登录。
- 点击「切换账号」会执行上述步骤并打开新的扫码窗口。完成登录后，需要重新勾选自动探索并保存；也可手动探索。
- 普通聊天、记忆、已经分享的手记、频率与每日限额保留；旧账号尚未分享的笔记取消待发送状态，避免切换后继续自动分享。
- 浏览器中的原生确认框会在探索页显示「确认网页操作 / 取消网页操作」。自动探索期间不会自动接受网页确认操作。若提示登录文件占用，先关闭宠物打开的小红书窗口再重试，无需删除整个 `data` 目录。
