# 自然聊天

在「设置 → 形象与人设 → 聊天风格」选择 **自然俏皮**。v0.11.1 起，这个选项同时控制普通聊天和主动分享；桌宠、网页、微信、QQ 共用后端规则，语音识别后的文字也走同一条聊天链路。已保存的名字、人设、记忆和历史不改写。选择「按自定义人设聊天」时，不附加自然聊天和对话节奏规则。

## 这次调整

- 先接具体内容：吐槽不自动变成安慰加建议，分享好消息不泛泛夸人。
- 闲聊允许一句结束，不固定追问或硬找新话题；「可以」是在确认任务时，仍应继续完成任务。
- 自然风格优先于旧人设里的固定称呼、撒娇和长篇安慰格式，保留角色性格。用户明确要求角色互动、详细解释或某种输出格式时照常处理。
- 参考本会话最近三条宠物回复：反复问句收尾、相同开头或连续长回复，会生成针对下一轮的节奏提醒。只计算这些特征，不把历史文字拼成新指令，不跨会话取资料。
- 主动分享围绕一个有意思的具体细节说两句，避免多篇笔记摘要、硬拉用户兴趣和固定的「你怎么看」。资料重复或无趣时可以不分享。

模型仍在同一次请求里生成答案。没有增加第二次改写请求，也没有把回答硬截成固定字数或按禁词删句，因此代码、引用和详细解释仍可完整输出。技术、图片、来源真实性及已有会话隔离规则继续生效。宠物不会靠编造现实生活经历来伪装成人。

## 本机体验检查

下表是人工验收场景，不是实际模型生成结果。无需清空聊天记录，可在原会话中体验；旧历史只保留事实语境，不要求模型继续模仿原文风。

| 对话场景 | 期望行为 |
| --- | --- |
| 「在吗」 | 很短的回应，不自我介绍或询问能帮什么 |
| 「下班路上又堵了一小时」 | 接堵车这个槽点，不自动列放松方法 |
| 「我就吐槽一下，别给建议」 | 接受边界，后续几轮也不马上说教 |
| 「嗯，晚安」 | 自然收尾，不追加问题 |
| 上轮说要给三种方案，本轮答「可以」 | 继续给方案，而非只回「好呀」 |
| 连续两轮以问句结束后，用户说「随便聊聊」 | 可以分享自己的观点，不继续查户口 |
| 「Android 蓝牙连接失败，详细说下排查步骤」 | 保留实际需要的步骤、条件和代码，不为短句省略关键内容 |
| 「把‘还有什么可以帮你’翻译成英文」 | 正常翻译，不把引用当成必须删除的套话 |
| 「你刚才说亲眼看到了，是不是真的」 | 按实际取得的图片、文字或笔记证据说明，不编造经历 |
| 主动探索取得三篇笔记 | 挑一个具体细节分享，或者选择不分享，不拼成资讯合集 |
| 切换为自定义人设 | 不再附加自然风格和最近三轮的节奏提醒 |

自动测试验证的是提示词接入、会话隔离、历史保持、请求去重、结构化 QQ 回复兼容和主动分享路径；自然程度仍需要用实际配置的模型体验。不会使用测试夹具的固定回复声称已经完成真实模型对话评测。若仍有明显套话，连续两三轮的原对话比单独一句更有助于继续调整。
